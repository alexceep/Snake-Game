# 🐍 Snake Game

Projeto de um aplicativo inspirado no clássico jogo da cobrinha, acompanhado de um site que apresenta o funcionamento do app e permite o download.

---

## 🎮 Sobre o projeto

O **Snake Game** é um aplicativo baseado no famoso jogo retrô onde o jogador controla uma cobra que cresce ao comer itens enquanto evita colidir consigo mesma ou com obstáculos.

O site foi desenvolvido para:
- Apresentar o funcionamento do jogo
- Explicar suas mecânicas
- Disponibilizar o download do aplicativo

---

## 🌐 Acesse o site

👉 https://alexceep.github.io/Snake-Game/

---

## 📱 Sobre o aplicativo

O aplicativo oferece uma experiência simples e divertida, com foco em:

- Controles intuitivos  
- Jogabilidade clássica  
- Crescimento progressivo da cobra  
- Sistema de pontuação  
- Desafio baseado em sobrevivência  

---

## 🧠 Como funciona o jogo

- Você controla a cobra  
- Come itens para crescer  
- Quanto maior, mais difícil fica  
- O jogo termina ao colidir com:
  - O próprio corpo  
  - Paredes (dependendo da versão)
